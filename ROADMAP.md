# Improving PaperPocket

Updated for the 1.3.0 beta. The current priority is a free, reliable Android beta.
Purchases, advertising, paywalls, Play Store publication, iOS, and a hosted
website are deferred. The long-term business goal is **US$10,000 cumulative
earnings**, with no deadline or revenue guarantee. See [PRODUCT_PLAN.md](PRODUCT_PLAN.md).

The first version establishes image import, page arrangement, rotation, document filters, perspective crop, scanner integration with a full-resolution camera fallback, PDF conversion, a private document library, viewing, sharing, and saving copies. Its Android build and device acceptance checks must pass before treating it as ready for release. See `MANUAL_TESTS.md` for the validation checklist.

## Next iteration: reliability

1. Run the acceptance checklist on physical Android devices and fix confirmed defects, especially camera/scanner handoffs, process recreation, provider exports, and low-storage failures.
2. Version 1.3 moves normal and ID-card PDF creation into a foreground service with saved progress/result, cancellation, and optional notifications. It continues while minimized and across activity recreation; force-stop/reboot/process termination do not auto-resume. Import, compression, merge/extraction, and OCR remain in-app operations; evaluate moving those next only when phone feedback warrants it.
3. Add crash-safe cleanup of abandoned temporary files and unreferenced draft images. Preserve files needed by active camera, crop, or export operations.
4. Version 1.2 adds persistent document Trash, Undo/Restore, and confirmed permanent deletion. Add Undo for removing a draft page separately; document trash does not restore a removed draft image.

## Next iteration: scanning and editing

1. Add blur, lighting, and missing-corner feedback so users can retake a poor scan before exporting.
2. Improve local enhancement for shadows and receipts, with an adjustable intensity and before/after preview. Keep the original device photos intact.
3. Add a faster page organizer with drag ordering, multi-select actions, and virtualization for larger drafts/libraries.
4. Evaluate a camera scanner that works on devices without Google Play services, while retaining a clear permission explanation and a usable fallback.

## Later: document tools

1. Version 1.2 adds optional offline Latin/English text extraction with Copy/Share/Save TXT. Searchable PDFs, Urdu-script recognition, layout retention, and handwriting remain future work.
2. Version 1.2 adds lossless merging and ordered page extraction for supported PDFs generated by PaperPocket. General external-PDF import, richer split modes, and editing arbitrary PDFs remain future work.
3. Version 1.1 adds compression profiles and an original-preserving smaller copy with actual size savings. Continue measuring representative receipts, photos, and mixed documents; compression quality remains content-dependent.
4. Version 1.3 adds folders and Favorites without changing document bytes; deleting a folder keeps its PDFs. It also adds front/back ID-card copies on one A4 page. Evaluate annotations, signatures, and password protection after the basic workflow is stable.
5. Improve large-screen layouts and accessibility based on device testing and user feedback.

For each improvement, agree on the concrete user behavior, implement it, run the relevant acceptance checks, and document the remaining limits. Choose future work from observed problems and requested features.

## Release discipline

Keep each tested update in GitHub with a versioned download and a stable source
tag. `v1.2.0` preserves the previous stable version. Recover from a regression
with a corrected, higher-version-code APK signed with the existing key, rather
than asking testers to uninstall and lose private documents. Test in-place
updates and retain prior public download files. Play Protect warning work is
paused at the owner's request; a later Play submission remains a separate step.

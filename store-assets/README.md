# PaperPocket store artwork

- `app-icon-512.png`: opaque 512 × 512 PNG, matching the app's launcher icon.
- `feature-graphic-1024x500.png`: opaque 1024 × 500 PNG for the Play Store feature graphic.

The feature graphic is a document illustration, not a screenshot. Capture real
screenshots from the installed Android app for the store listing. Do not present
mock screens as screenshots or imply OCR, cloud storage, or PDF editing features

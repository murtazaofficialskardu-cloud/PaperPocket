# PaperPocket store artwork

- `app-icon-512.png`: opaque 512 × 512 PNG matching the launcher artwork.
- `feature-graphic-1024x500.png`: opaque 1024 × 500 PNG document illustration.
- `source/`: editable SVG source for both graphics.
- `beta-ui/`: three unchanged native API 36 emulator screenshots from the verified 1.2.0 source: Home, Pages, and My PDFs empty states, 1080 × 1920.

The feature graphic is an illustration, not a screenshot. The native UI images
show installed app behavior; they do not prove physical-camera scan quality.
Capture representative non-sensitive document flows on real phones before a
store launch. Text extraction is Latin/English and produces separate text;
searchable PDFs and Urdu OCR are not implemented. No hosting or store publication
has been performed by supplying this kit.
